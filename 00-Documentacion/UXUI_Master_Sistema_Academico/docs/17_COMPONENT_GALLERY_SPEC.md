# 17 — Especificación de Component Gallery

Antes de construir pantallas, el agente debe crear una ruta de desarrollo, por ejemplo `/ui-kit`, no enlazada en producción.

Debe exhibir:

## Tipografía
Display XL, H1–H3, body, small, micro.

## Color
Todos los tokens con nombre y hex.

## Botones
Primary, secondary, ghost, danger, icon; normal/hover/focus/disabled/loading.

## Inputs
Text, search, date, number, select, checkbox, radio, file upload; normal/focus/error/disabled.

## Badges
Estados académicos, programas, períodos y requerido/optativo.

## Cards
Metric, info, side panel, report card, period card.

## Progress
0, 34, 61, 78, 100%.

## Alerts
info/success/warning/danger.

## Tabs
2–6 tabs, active/disabled.

## Table
header, body, badge, progress, empty, pagination.

## Student header
con/sin foto; datos mínimos.

## Filters
desktop + responsive representation.

## Print sample
header/footer.

### Gate
No construir S01 hasta que esta galería sea aprobada visualmente. Esto reduce drift y evita que cada pantalla cree su propio botón, input o card.
